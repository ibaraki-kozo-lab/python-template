# data

計算に使う入力のデータを置く．元のデータは書き換えない．直したデータは別の名前のファイルにし，どう直したかを下の表に書く．

| ファイル | 中身 | 出典・作った日 |
|----------|------|----------------|
| `beams.csv` | はりの条件（テンプレートの例）．1行目は列の名前で，荷重 `p` [N]，荷重の位置 `a` [mm]（左端から），長さ `length` [mm]，ヤング率 `e` [N/mm2]，断面二次モーメント `inertia` [mm4] | テンプレートに付属 |

大きなデータ（数十MBを超えるもの）は，Gitに記録しない．ファイルの名前を `.gitignore` に書いて記録されないようにし，元のデータを置いた場所を上の表に書く．GitHubは，100MBを超えるファイルを受け付けない．
